AutoAudit.ai SaaS Overview

What AutoAudit.ai Does

AutoAudit.ai is a SaaS spend auditing platform for founders, finance teams, and operations teams. Its main job is to help a company find wasted software spend before contracts renew.

It lets a user build a SaaS vendor inventory with:

- Vendor name
- Category
- Owner name/email
- Monthly spend
- Seats purchased
- Active seats
- Last-used date
- Renewal date
- Notes

From that data, the app automatically detects:

- Zombie subscriptions: tools with no active seats or no recent usage.
- Unused seats: paid seats that are not being used.
- Duplicate tools: multiple tools in the same category, such as two project management apps.
- Renewal risk: vendors renewing soon, especially within 30 to 60 days.
- Estimated savings: annual savings based on wasted monthly spend and unused seat cost.

Main Product Features

1. Public Website

- Landing page explaining the SaaS waste-control offer.
- Early-access/founder-led positioning that explains the product is actively improving through real user feedback.
- Lightweight "How teams use AutoAudit.ai" workflow section: import vendor data, detect waste signals, review renewals, generate reports, and send AI drafts.
- Evidence-backed sample output section with realistic examples, such as Clearbit being flagged because 12 purchased seats show 0 active users.
- Trust and control section covering company-separated workspaces, hashed passwords, protected routes, role permissions, and human-reviewed AI.
- Planned integrations section for Google Workspace, Microsoft 365, QuickBooks, Stripe, Okta, and Slack alerts.
- Feedback section inviting early users to share workflow suggestions, missing features, and improvement requests.
- Pricing page with Free Trial, Starter, Standard, and Custom plans.
- Pricing page now explains that payment activation is founder-reviewed/manual during early access.
- Demo page.
- Demo page now shows evidence behind each sample vendor finding.
- Contact page.
- Privacy and Terms pages.
- About Developer page, which helps make the product feel founder-led and personal.
- Founder page now includes a clearer product story: why AutoAudit.ai was built, what problem it solves, and how feedback shapes the roadmap.

2. Authentication

- Signup with name, email, password, company name, company domain, and selected plan.
- Login with email/password.
- JWT-based session storage.
- Passwords are hashed using bcrypt.
- New signup creates a company workspace and makes the first user the owner.

3. Protected Dashboard

Dashboard sections include:

Overview

- Shows total monthly spend, estimated savings, active vendors, waste found, unused seats, renewal exposure, charts, and action summaries.

Vendors

- Users can add, search, filter, import, and delete vendors.
- CSV import is supported, including a downloadable CSV template.

Waste Detection

- Shows detected waste signals: zombie apps, unused seats, duplicate tools, and high-impact cleanup opportunities.
- Explains that AI suggestions are reviewed by users and do not automatically contact vendors or change subscriptions.
- Empty state now guides users to add seat counts, active users, last-used dates, and renewal dates for better evidence.

Renewals

- Tracks upcoming vendor renewals.
- Lets users export renewal dates as an .ics calendar file.
- Empty state now explains how renewal dates build the owner review queue and contract exposure view.

Reports

- Generates and stores AI-powered SaaS waste reports, including CFO-style summaries.
- Empty state now asks for vendor evidence before report generation and explains what the report will include.

AI Email Generator

- Creates vendor emails for cancellation, renegotiation, or seat reduction.
- Clarifies that AI only drafts emails. Users review and edit drafts before sending, and AutoAudit does not contact vendors automatically.

Plan/Billing

- Shows plan limits and usage, such as vendors added, reports generated, AI emails generated, and AI analyses used.

Settings

- Includes company settings like CFO approval threshold, weekly renewal digest, auto-draft cancellation emails, and managed renegotiation preference.

4. AI Features

The backend uses OpenAI's Responses API to generate:

- Cancellation emails.
- Renegotiation emails.
- Monthly SaaS waste reports.
- Vendor waste explanations.
- Duplicate-tool consolidation suggestions.

The AI is instructed not to invent contract terms, dates, discounts, or benchmarks. That is a good trust decision.

The product now also makes the human-review guardrail visible in the UI:

- AI generates recommendations, reports, and drafts.
- Users review everything before action is taken.
- AutoAudit.ai does not autonomously cancel subscriptions.
- AutoAudit.ai does not email vendors automatically.

5. Plan Limits

Current limits include:

- Free trial: 10 vendors, 1 report, 3 AI emails, 3 AI analyses.
- Starter: 50 vendors, 3 reports, no AI emails/analyses.
- Standard: 200 vendors, 25 reports, 100 AI emails, 50 AI analyses.
- Custom: unlimited/custom limits.

6. Security and Admin Features

- Role-based permissions: owner, admin, member.
- Only admins/owners can create or edit vendors.
- Only owners can delete vendors.
- Audit logs are created for vendor changes.
- Admins can view audit logs.
- Helmet security headers.
- CORS allow-listing.
- Rate limits for API, auth, and AI routes.
- Safer error handling with request IDs.
- MongoDB tenant scoping by company.

Possible Improvements To Gain User Trust

Highest-impact trust improvements:

1. Add real billing with Stripe

Right now there are plan pages and limits, but no real payment flow. Stripe Checkout or Billing would make the SaaS feel production-ready.

2. Add a trust/security page

Explain encryption, password hashing, data separation by workspace, rate limits, audit logs, and AI data usage. Some trust microcopy now exists on the landing page and pricing page, but a dedicated page could still help later.

3. Add clear "AI does not take action automatically" messaging

Users should know AI drafts emails and reports, but humans review before sending. This has now been added to the landing page, demo page, dashboard waste section, and AI email generator.

4. Add source/evidence display for every recommendation

For example: "Slack flagged because 28 of 80 seats are unused, estimated annual waste $3,738." The public sample output and demo page now include this style of evidence, but deeper in-dashboard per-finding evidence can still be expanded.

5. Add onboarding checklist

Some exists inside the dashboard, but it can be stronger: add sample data, import CSV, review waste, generate first report, create first email.

6. Add integration roadmap section

The app now includes visible planned integrations: Google Workspace, Microsoft 365, QuickBooks, Stripe, Okta, and Slack alerts.

7. Add exportable reports

PDF export, CSV export, and shareable report links would make the product more useful for CFOs.

8. Add testimonials or founder note with real contact

The founder-led section is good. Add a real support email, LinkedIn, or quick call CTA.

9. Improve admin/team management

The backend has roles, but the product would feel more complete with invite users, change roles, remove users, and owner transfer.

10. Add integrations

Big trust jump if users can connect Google Workspace, Microsoft 365, Okta, Stripe/Ramp, QuickBooks, or bank/card feeds instead of manually entering everything.

Short Summary

AutoAudit.ai is already a solid SaaS audit MVP. The strongest current value is: import/add vendors, detect waste, track renewals, generate AI reports/emails, and manage the workspace securely.

The latest trust update makes the site feel more founder-led, transparent, and realistic while keeping the current layout and workflow intact.

The next big trust jump is real payments, deeper in-dashboard evidence trails, exports, team management, and live integrations.
